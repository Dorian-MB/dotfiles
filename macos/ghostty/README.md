# Ghostty

Config du terminal [Ghostty](https://ghostty.org), le terminal principal.

- Fichier : `config`. Le dossier est lié à `~/.config/ghostty` (`./install.sh macos/ghostty`).
- Catppuccin Macchiato, `JetBrainsMono Nerd Font` 19, fond à 85 % d'opacité avec flou, pas de barre de titre ni d’onglets, fenêtre maximisée à l’ouverture.
- `Option` gauche = `Alt` (nécessaire pour les raccourcis AeroSpace et nvim).
- Supporte nativement le protocole graphique kitty : figures matplotlib dans nvim (jupynb.nvim).

## Raccourcis clavier

| Touche | Action |
|---|---|
| `Cmd+]` / `Cmd+[` | split suivant / précédent |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | envoyés tels quels à nvim (`<C-Tab>` = fichier précédent) au lieu de changer d'onglet |
