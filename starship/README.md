# starship

Config du prompt [starship](https://starship.rs), chargée par `zsh/.zshrc` (`eval "$(starship init zsh)"`).

- Fichier : `starship.toml` → `~/.config/starship.toml` (`./install.sh starship`)
- Le format est celui par défaut. Le fichier ne fait que redéfinir les symboles de chaque module (langages, git, cloud…) avec des icônes Nerd Font.
- Police requise : `JetBrainsMono Nerd Font`.

Pas de raccourcis clavier.
